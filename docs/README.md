# Documentation

SpeechMetricHub separates the question **what is measured?** from **what reference is needed?** and **which tasks might use it?** Read the protocol before comparing numbers.

## Getting started

1. [Install the required scorer groups](INSTALLATION.md).
2. [Run a Python or CLI example](API.md).
3. [Choose an exact metric ID](METRICS.md).
4. [Fix the evaluation protocol](PROTOCOLS.md).
5. [Provision optional models](MODELS.md), then inspect the [validation evidence](../validation/README.md).
