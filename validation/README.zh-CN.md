# v0.2.0 验收范围

完整矩阵见 [summary.json](summary.json)。**69 个注册入口全部实际调用通过：64 个明确指标，5 个兼容别名。** 别名不充当指标覆盖面。

- 标准指标：33 个接口，使用真实语音/多源数组或明确标注的转写、活动、评分 fixture；对照原生计分器或解析期望值。
- 模型指标：16 个模型家族，真实 LibriMix 语音、独立参考语音与可控噪声；每个声明的输出均返回有限值。
- 模型异常输入：16×4=64 组，覆盖短音频、立体声、静音、缺失文件；失败返回原因且没有数值。
- 原生调用数值对照：AE、SCOREQ 四种组合、NISQA、UTMOS、DNSMOS，共8组；每个输出绝对误差小于1e-5。
- 相同音频性质：RawNet3、IPA 字符相似度、SpeechBERTScore 三项、natural-reference SCOREQ，共6项通过。
- 29 个单元/语义/汇总测试通过，包括时间漂移、说话人置换、错误计数、TS目标约束、完整集覆盖、DER micro、空参考插入、非法波形。
- 新建、不继承训练环境的 Python 3.10 虚拟环境，安装包、依赖检查、29项测试和 CLI 均通过；确认从 site-packages 导入。

模型验收在 Linux 验证环境 / Linux / Python 3.10 / CPU 完成，限制2线程，不使用训练GPU。模型环境采用已有 torch28 环境的只读继承与隔离覆盖；`pip check` 通过。精确版本、官方提交和25个外部文件/目录的内容指纹见 [environment.json](environment.json)。模型权重不随包分发。所有模型均进行过真实推理，不再以外部桥接模板替代验收。

本次没有进行：全新环境中重新下载全部模型依赖、GPU等价性、Windows上的全部神经模型、完整基准测试集成绩复现、GitHub Actions远端执行、Docker镜像构建。工作台既有转写口径的50样本结果另做部署回归。

当前验证回答“这些具体接口在记录的环境和配置下能否正确调用、保留全部输出”。它不保证对所有语言/失真类型有效，也不代表模型预测等于人工MOS。详细原始日志与完整路径配置保留在部署验收目录；公开矩阵只保留必要指纹和数值。

复验入口为 `scripts/validate_models.py --help`，提供部署配置、待测/干净/非匹配参考音频及真实参考文本即可逐家族重跑；每个已声明输出都会保存。标准算法与语义测试使用 `python -m unittest discover -s tests -v`。
